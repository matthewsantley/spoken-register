Contribute

The register is an open data file. Anyone can add a word from their language or propose an object for naming.

Add a word from your language

This is the contribution that matters most. The pool currently holds words assembled from reference sources, none of them confirmed by a speaker. Every entry has a vouched_by field sitting empty.

The rule for the pool is narrow on purpose: the word must mean star, sky or moon. No mythology, no heroes, no place names. Just the plain noun, so that no culture's stories get imposed on anybody else's sky.

If you speak a language that is missing, or you can confirm or correct a word already listed, that is the most useful thing you can send. The full word list is here, grouped by language, with a one-click way to confirm or flag each entry.

Check a proposal

These panels do not save anything — the register is only ever changed by the command-line tool. They tell you what would be issued and print the exact line to submit.

How assignment works

  

    
The catalogue identifier is hashed to a position in the word pool. If that word is already used in that constellation, the position steps forward until it finds a free one, so no language piles up in one region of sky. No person picks which language goes with which star.

    
The hash runs once. After that the name is stored in register.json and that file is the authority. Nothing recalculates a name that has already been issued.

    
That rule matters more than it looks. If names were regenerated on demand, inserting a word into the middle of the pool rather than appending it would silently shift every name in the register. Issue once, append, never recompute.

    
Adding an entry means running issue.py add "TOI-2109 b" Cyg "ultra-hot giant", then issue.py check to validate, then issue.py sync. Full instructions are in the repository README.
