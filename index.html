What this is

Catalogue names like Kepler-452b work perfectly well for astronomers and hopelessly for everyone else. The number means nothing, so there is nothing to hold on to. Broadcasters either read it out and lose the room, or avoid naming anything at all.

The Spoken Register does not replace those names. It adds the layer nobody built: a second name, meant for saying out loud.

Each one has two parts. The first says where to look — the standard abbreviation for the constellation the object sits in. The second is a word meaning star, sky or moon, taken from a language somewhere on Earth. Every culture has looked up and named what it saw, so the sky gets named, in every language, after the sky. A closing vowel marks which planet in the system.

Nobody chooses which language goes with which star. An algorithm decides, once, and the answer is written down permanently.
